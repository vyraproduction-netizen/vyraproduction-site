# VYRA Production site preview

This `docs/` directory contains a host-independent English static site preview. It has no affiliate links, scripts, forms or analytics. Every page is marked `noindex,nofollow` until site details and publishing host are verified.

Open `docs/index.html` locally to review the content. Before publishing: verify the responsible operator identity and privacy details, select a host suitable for a commercial affiliate site, link the publisher's generated articles to these pages, check any partner program terms, and update the privacy notice if tracking or analytics is enabled.

The GitHub Pages publisher integration remains isolated in `vyra-publisher-test` for diagnostics. Its source repository upload could potentially feed a separate static host, but that publishing path needs a separate controlled verification before use.
